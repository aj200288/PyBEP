{# Refreshing means "start over": a reload replaces itself with the run page, reset — the same place the mark in the corner goes, so the browser's refresh button and the logo do the same thing. Included from base.html so every page answers a refresh the same way. This used to sit on the results page alone, which left a refresh meaning something different everywhere else: the front page and the instructions simply came back as they were, and the pages a POST produces — Confirm columns, and both steps of Format Data — asked the browser whether to send the form again. The browser reports how the page was loaded, so this is the reload itself rather than a guess at one. replace() rather than assigning to href, so a refresh leaves no extra step behind for the back button. Expects no context. Goes first in the body, before there is any page to parse or paint. #}
