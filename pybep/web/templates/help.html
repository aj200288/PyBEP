Instructions

PyBEP takes a measured full-cell OCV curve and works out which cathode and which anode, combined and scaled how, reproduce it most closely.

Data files

Every curve, whatever it describes, is just two columns of numbers: state of charge and voltage. Files may be .txt, .csv or .xlsx, up to {{ max_upload_mb }} MB.

  • Two numeric columns at least. One holds SOC, the other voltage. If the file has more, you pick which is which after uploading.
  • The separator is detected for you — commas, semicolons, tabs or spaces — as is the decimal mark, so 0,85 and 0.85 both work.
  • Headers and footers are ignored. Lines of text above or below the numbers are stripped automatically. Text in the middle of the numbers is rejected, because at that point there is no way to tell a stray label from corrupted data.
  • SOC may be 0–1 or 0–100. Anything reaching past 1.5 is read as a percentage and divided by 100.
  • Order does not matter. Curves that run backwards, or wander out of order, are sorted and flagged. Repeated SOC values are nudged apart.
  • At least four rows of data.

Every curve is finally resampled onto a common grid of 1001 points, which is what makes different sources comparable.

Anything unusual in your file produces a note above the results rather than a silent correction — read those notes; they are the difference between a fit and a coincidence.

Running an optimization

  1. Choose the battery OCV curve. This is your measurement: the full-cell curve to be decomposed. Pick one of the {{ battery_library|length }} bundled examples to try the tool out, or upload your own.
  2. Check the candidates. {{ cathode_library|length }} reference cathodes and {{ anode_library|length }} reference anodes are built in and all selected by default, so you can usually leave this alone. Open a panel to see the list, preview any curve, or untick ones that cannot apply to your cell. Fewer candidates means a faster run. You can add your own files for a material that is not in the list; those are used for that run only and are not added to the shared list.
  3. Set iterations. The search starts from random points, so each run can land somewhere slightly different. More iterations repeat it and keep the best, trading time for consistency. Start at 1 while you are finding your way, raise it for a result you intend to keep.
  4. Set the weights. These decide what “closest” means. Battery weight fits the voltage curve itself. Differential capacity weight fits its derivative instead, which is far more sensitive to the position of peaks and plateaux — the features that identify a material. The two always sum to 1, so moving one moves the other. Fit on voltage alone and a smooth curve can hide a wrong material; add derivative weight to make the peaks matter.
  5. Confirm the columns. Only for files you uploaded: PyBEP shows the first few rows with its guess pre-selected, and you correct it if the guess is wrong. Built-in curves skip this step because their layout is already known.

Reading the results

The graph overlays your measured curve with the reconstruction, plus the cathode and anode curves that produced it. Dashed sections are the parts of each electrode curve lying outside the window actually used in the fit.

Best cathode / anode ID
Which candidates won, named by their file.
Best parameters
The four indices marking where each electrode curve was cut and stretched to line up with the cell.
Lowest RMSD
Root-mean-square deviation between measurement and reconstruction, in volts — lower is better. It is only comparable between runs using the same weights, since changing them changes what is being minimised.

A winner is always reported, even when nothing fits well. The RMSD, and your own eye on the graph, are what tell you whether the answer means anything. If the best fit is poor, the right material is probably not among the candidates.

Download the numbers as JSON, CSV or Excel. All three describe the same run. JSON keeps full precision; Excel stores about 15 significant digits, so use JSON if the last digits matter. Adjust settings and re-run keeps the same curves and only changes the settings — the quick way to see how sensitive a result is to the weights.

Formatting data

Format data runs the same cleaning on your files and hands them back as a zip, without optimizing anything: each becomes a plain two-column, 1001-point file. Use it to standardise a set of measurements, or to see exactly what PyBEP made of an awkward file. Files in one batch must all be the same kind of curve, since the type decides which orientation is expected — rising voltage for cathodes and full cells, falling for anodes.

Limits

The optimization compares every cathode against every anode, so the work grows as cathodes × anodes × iterations. To keep the site responsive:

  • at most {{ max_files }} cathode and {{ max_files }} anode candidates
  • at most {{ max_iterations }} iterations
  • uploads up to {{ max_upload_mb }} MB

Uploaded files live only in your own session. They are deleted when you start another run, and are never added to the built-in list that other people see.
