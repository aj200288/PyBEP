{# Shown while a run is going. A form POST leaves the browser sitting on the old page with nothing to show for it, sometimes for most of a minute, which reads as "nothing happened" — so the submit that starts a run puts this up and the page that answers takes it away. It goes where the button was: the buttons stand down and the battery takes their place, so the answer to "did that do anything?" is in the spot the user just clicked. Nothing else on the page moves, which leaves the last graph and the notes on the data there to read while it works. Belongs at the end of a form marked class="js-long-run" — that class is what the script below goes by, and the CSS hangs the swap off it. The download form on the results page deliberately does not carry it: it never navigates, so a battery raised for it would never come down. #}
