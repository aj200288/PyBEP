Fitting

{% call help.field('iterations', 'Iterations (1–' ~ max_iterations ~ ')', 'slider-iterations') %}

How many times the whole search is repeated. It starts from random values each time, so two runs on the same data can settle in slightly different places; repeating it and keeping the best result is what makes the answer steady.

One is enough while you are finding your way. Raise it for a result you mean to keep — {{ max_iterations }} is the most allowed, and takes roughly {{ max_iterations }} times as long.

{% endcall %}
Value: {{ iterations }}
More iterations give more consistent results but take longer.
{% call help.field('battery-weight', 'Battery weight (0–1, step 0.05)', 'slider-a', 'weights') %}

How much the fit cares about the voltage curve itself — the shape drawn on the graph. At 1 it is the only thing being matched.

Voltage alone can mislead. An OCV curve is smooth, and more than one pair of electrodes will follow it closely enough to look right; the weight below is what tells them apart.

{% endcall %}
Value: {{ "%.2f"|format(battery_weight) }}
{% call help.field('derivative-weight', 'Differential capacity weight (0–1, step 0.05)', 'slider-b', 'weights') %}

How much the fit cares about dQ/dV — the derivative of the curve rather than the curve. The peaks and plateaux there are the features that identify a material, so this separates one candidate from another far more sharply than the voltage does.

The two weights always add to 1, and moving one moves the other. Some weight here is usually worth having; all of it stops the voltage level mattering at all.

{% endcall %}
Value: {{ "%.2f"|format(derivative_weight) }}
The two weights always add up to 1 — moving one moves the other.
